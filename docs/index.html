📡 توثيق مشروع: 80211Probe

أداة متقدمة لتحليل إطارات شبكات Wi-Fi (IEEE 802.11) - مبنية بلغة Pure Python

1. المشكلة (The Problem)

تنتقل البيانات في الشبكات اللاسلكية (Wi-Fi) على هيئة تيار من البيانات الثنائية (Raw Bytes) غير المفهومة للبشر. يعاني محللو الأمن السيبراني من أن أغلب أدوات فحص الشبكات تعتمد على مكتبات خارجية جاهزة تقوم بالعمل بالنيابة عنهم، مما يمنع الفهم العميق لكيفية بناء الإطارات (Frames) وكيفية التلاعب بها أو استخراج الأدلة الجنائية منها.

2. فكرة المشروع (Project Idea)

بناء أداة هندسية وأمنية (80211Probe) تعمل من واجهة سطر الأوامر (CLI)، قادرة على قراءة البايتات الثنائية الخام لإطارات IEEE 802.11 وتحليلها بتّاً بـ بت (Bit-by-Bit) باستخدام العمليات الثنائية، وذلك لاستخراج تفاصيل دقيقة مثل: نوع الإطار، عناوين الـ MAC للمرسل والمستقبل، واسم الشبكة (SSID). تم بناء المشروع بالكامل باستخدام بايثون الخالصة (Pure Python) دون أي مكتبات خارجية لتنفيذ جوهر الفكرة.

3. الهدف (The Objective)

  • التطبيق العملي لمفاهيم الأمن السيبراني والتحليل الجنائي للشبكات (Network Forensics).
  • الاستغناء عن المكتبات الجاهزة وبناء (Parser) من الصفر للتعامل مع Endianness والبتات.
  • بناء أداة قابلة للتوسع وتدعم معالجة الأخطاء بذكاء بحيث لا تنهار الأداة عند إدخال بيانات تالفة.
  • فصل معمارية المشروع (Architecture) إلى طبقات: القراءة، التحليل، الواجهة، والتقارير.

4. طريقة التشغيل (How to Run)

الأداة مصممة للعمل كأداة اختراق وتحليل احترافية عبر سطر الأوامر (CLI)، وتدعم الخيارات التالية:

# لمعرفة تفاصيل الأداة والأوامر المتاحة
python main.py --help

# لمعرفة رقم الإصدار
python main.py --version

# لتحليل ملف شبكة ثنائي وعرض النتائج كنص عادي
python main.py parse sample_beacon.bin

# لتحليل إطار تجريبي مدمج داخل الأداة
python main.py parse --demo

5. النتائج والمخرجات (Outputs)

تدعم الأداة ثلاثة أنواع من المخرجات الاحترافية:

  • المخرجات النصية (Standard Output): ملخص سريع ومباشر على الشاشة يوضح (النوع، المرسل، الـ BSSID، واسم الشبكة).
  • مخرجات JSON: عبر إضافة خيار --json، تقوم الأداة بتصدير البيانات بصيغة مفهومة للآلة لاستخدامها في أدوات أمنية أخرى.
  • تقارير HTML: عبر إضافة خيار --html، تقوم الأداة بتوليد تقرير ويب تفاعلي وجميل يسهل قراءته وتحليل الأدلة الجنائية من خلاله.

تم تطوير هذا المشروع كمتطلب أكاديمي لتقييم مهارات الأمن السيبراني وهندسة البرمجيات.
